# 🎲 Ultimate Tenzies Challenge

A modern, fun **dice game** built with **React**.  
Roll the dice, lock matching numbers, and aim to get all ten dice showing the same value.  
Can you beat your **best score**?

## 🚀 Features

- 🎲 **Interactive Gameplay** – Roll dice and lock your numbers.
- 💾 **Best Score Tracking** – Saves your lowest roll count in `localStorage`.
- 🎉 **Winning Confetti Animation** – Celebrate your victory!
- 🌙 **Modern UI Design** – Smooth glow effects and vibrant success color `#16A34A`.

---

## 🧠 Technologies Used

- React (Vite or Create React App)
- CSS3 for UI & effects
- `nanoid` for unique dice IDs
- `react-confetti` for celebration effect
- LocalStorage for persistent high score

## 🕹️ How to Run Locally

```bash
# 1. clone
git clone https://github.com/<your-username>/react-tenzies-challenge.git

# 2. go in
cd react-tenzies-challenge

# 3. install
npm install

# 4. run (Vite)
npm run dev

# or if CRA
npm start
